CyberDNA — beginner-friendly Flask dashboard

1. Extract this ZIP and open the CyberDNA_Fixed folder in VS Code.
2. Open Terminal > New Terminal and run:
   py -m venv .venv
   .venv\Scripts\activate
   py -m pip install -r requirements.txt
   py app.py
3. Open http://127.0.0.1:5000
